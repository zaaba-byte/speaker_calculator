# round_cut_sheet.py README

Usage:
1. Save this script in ~/Documents/speaker_calculator
2. Run with:
   python3 round_cut_sheet.py

Input:
- Paste your entire cut sheet block (e.g. "Front Panel: 29.83 × 45.56")
- End input with a blank line, then press Ctrl+D

Output:
- Script prints both calculated values and rounded values side by side
- Panels → rounded to whole numbers
- Ports → rounded to 1 decimal place
